# GearsOfWarDatabases.github.io

The home page of [Gears of War Databases](https://github.com/GearsOfWarDatabases), at
<https://gearsofwardatabases.github.io/>: every game's database, in release order, and the templates to make one.

One static page, `index.html`, served as it is (`.nojekyll`): Settings → Pages → Deploy from a branch, `main`,
`/ (root)`. The games are the `GAMES` list in its script; when a database goes up, set `live: true` (and
`ref: true` if it has a Reference repository) on its line.

Each database is its own repository, published under this address: `GoW5DB` at
<https://gearsofwardatabases.github.io/GoW5DB/>, and so on.
